# 🧮 Calculadora Simples

Uma calculadora funcional e responsiva desenvolvida para praticar conceitos fundamentais de desenvolvimento web front-end.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

* **HTML5:** Estruturação dos elementos da calculadora.
* **CSS3:** Estilização, layout (Flexbox/Grid) e design responsivo.
* **JavaScript:** Lógica de programação para as operações matemáticas e manipulação do DOM.

## 📋 Funcionalidades

- Operações básicas (Soma, Subtração, Multiplicação e Divisão).
- Limpeza do visor (Botão C/AC).
- Interface intuitiva.
- Adaptável para dispositivos móveis (Responsivo).

## 🧠 Aprendizados
Este projeto foi fundamental para reforçar:
* Manipulação de eventos no JavaScript (Click).
* Lógica de encadeamento de operações matemáticas.
* Aplicação de variáveis CSS para manter um design consistente.
